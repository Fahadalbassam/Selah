## English wording and layout checks
- Every label of the cycle is English: **Start work**, **Send for review**, **Send for review now**, **Save without sending**, **Sign off (first of two)**, **Second sign-off and verify**, **Request revision**, **Verified**, **Waiting for the firm**. The only Arabic on the screens is data (action, project, recommendation and evidence-item titles, person names) and the **عربي** switch.
- Two near-duplicates of one idea: the status chip says **Verified**, the dialog and the project's activity line say **Verified Complete** ("It becomes Verified Complete"; "moved Awaiting review to Verified complete").
- **Reviews asking for changes 33%** on the Progress tab has no number beside it (1 of 3?), so it reads as a score.
- **Waiting for the firm** and "With the consultant since …" say the same thing twice on the owner's page.

## Four answers
1. **Could a real person do this without help?** Yes. The owner always saw one next step, the two consultants saw the decision they were asked for, and the second sign-off was refused to the first signer without anyone having to explain it.
2. **Anything break, lose data, show the wrong thing, or show something to the wrong person?** Nothing wrong shown. The mail goes Arabic first even to an English reader. Nothing lost; the save after **Start work** needs about 1.5 s and a page left earlier does not save.
3. **Did Selah act like the consultant?** No. It asked for a second human, the second sign-off is a person's button with a plain dialog, the weak draft was never judged for the owner.
4. **One change:** store each person's language and put it first in the mail (and let the home **Start work** button start the work, or call it **Open**).
